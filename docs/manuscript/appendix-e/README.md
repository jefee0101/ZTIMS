# Appendix E: DOT tourism statistics report forms

Blank copies of the DOT forms that ZTIMS's accommodation and attraction
reports follow, for the manuscript's Appendix E. Taken from the PDFs the user
supplied (the Bataan same-day-visitor sample file is left out). `stitch.py`
rebuilds them from 200 dpi renders of those PDFs:

- Accommodation: DAE-1A (1 page); DAE-1B v4a daily (3 pages); DAE-1B / DAE-2
  2019 monthly (3 pages); FORM A annual (3 pages). These print as whole pages
  already and are unchanged.
- Attraction: VAR 1, VAR 2, VAR 3M and DTA2M were printed with their tables
  cut across 4, 2, 3 and 2 pages. The pieces are joined into one table each,
  the white seams closed, the DTA2M heading "Foreign Country Residence" (cut at
  the page edge) redrawn, and VAR 2's one sample entry (period, municipality,
  "Lagbangan Lake") blanked to "Attraction 1" like the other rows.

Wide forms are saved turned 90° so they fill a portrait page.
